# تثبيت نسخة المطعم 0.4.0

الإصدار الحالي خاص بالمطعم وواجهة ChatGPT. لا توجد فيه جلسات واتساب أو مفاتيح
Meta أو منافذ مكالمات. صفحة العميل / والإدارة /admin والمندوب /courier.

لم تُبنَ حزمة توزيع 0.4.0 بعد؛ release.json يصرّح بحالة unbuilt ولا يحتوي
بصمة أرشيف معتمدة. سيرفض بناء المثبّت استخدام أرشيف قديم غير مطابق. بعد بناء
صورة الإصدار الجديد والتحقق منها يُحدّث البيان ببصمتها قبل توزيع المثبّت.

ينشئ المثبّت حسابات التطبيق وقاعدة البيانات الخاصة بكل نسخة، ويتحقق من ملكية
الحاويات ووحدات التخزين وتطابق الإصدار قبل إعادة تشغيل نسخة موجودة. لا يعامل
نسخة أقدم بوصفها ترقية ضمنية. خيارات --media-port و--media-bind و--public-ip
المخصصة للمكالمات مرفوضة في الإصدار الجديد. اضبط --http-port و--http-bind
و--public-url عند الحاجة، ثم HTTPS والمنيو وبوابة الدفع المأذونة بصورة مستقلة.

لا تحذف ملفات .env القديمة أو قواعد بيانات/تسجيلات واتساب دون نسخة احتياطية
وموافقة مستقلة. الاستعادة البرمجية متاحة عبر before-whatsapp-removal-20261009.
